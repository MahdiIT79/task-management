
# HTTP Status Codes

| Method | Endpoint | Status Code | Description |
|---|---|---|---|
| POST | /users | 201 | User created |
| GET | /users | 200 | Users retrieved |
| GET | /users/{id} | 200 | User retrieved |
| GET | /users/{id} | 404 | User not found |
| DELETE | /users/{id} | 204 | User deleted |
| POST | /tasks | 201 | Task created |
| GET | /tasks | 200 | Tasks retrieved |
| GET | /tasks/{id} | 200 | Task retrieved |
| GET | /tasks/{id} | 404 | Task not found |
| PUT | /tasks/{id} | 200 | Task updated |
| DELETE | /tasks/{id} | 204 | Task deleted |
